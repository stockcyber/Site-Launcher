## 📌 Sobre o projeto

Este é um projeto simples feito em **Python** que cria um menu interativo no terminal.

O usuário pode escolher opções para:

- 🌐 Abrir meu GitHub
- 🐍 Abrir o site oficial do Python
- ❌ Sair do programa

O sistema também:

- Limpa a tela automaticamente
- Muda a cor do terminal
- Mostra uma arte em ASCII
- Exibe mensagem de boas-vindas
- Simula carregamento

---

🛠️ Tecnologias usadas
Python 3

Biblioteca os

Biblioteca time

Biblioteca webbrowser

Biblioteca sys

📂 Como funciona o código
🔹 1. Abre links automaticamente
webbrowser.open("https://github.com/rafaelkkj123rs")
Usa a biblioteca webbrowser para abrir sites no navegador padrão.

🔹 2. Comandos do sistema
os.system("cls")
os.system("color b")
os.system("title Projeto de abrir site")
cls → limpa o terminal

color b → muda a cor

title → muda o título da janela

🔹 3. Menu interativo
O programa usa:

while True:
Isso cria um loop infinito até o usuário escolher sair.

Depois usa:

input("Digite: ")
Para receber a escolha do usuário.

▶️ Como executar
Instale o Python

Salve o arquivo como main.py

Execute:

python main.py
